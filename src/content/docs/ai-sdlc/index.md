## Purpose

A pragmatic model for adopting agents in software delivery, from teams to the organization.

## Team level

Expand agent use from local development to autonomous implementation.

| Capability                    | Application                                                                      |
| ----------------------------- | -------------------------------------------------------------------------------- |
| **Assisted development**      | Coding agents help developers implement, test, refactor, and understand code.    |
| **Automated review**          | Agents review changes, first as feedback, later as enforced gates.               |
| **Incident intelligence**     | Agents analyze incidents, triage findings, and create or enrich tickets.         |
| **Autonomous implementation** | Agents implement bounded tasks, run checks, and submit changes for human review. |

## Organization level

Make agent adoption reusable, governed, and safe across teams.

| Capability             | Application                                                                    |
| ---------------------- | ------------------------------------------------------------------------------ |
| **Centralized access** | One governed exit point to approved tools and services, with usage visibility. |
| **Curated registries** | Catalogs of approved skills, tools, and templates, with review and versioning. |
| **Safe execution**     | Sandboxed environments and traceability for agent workloads.                   |
